# Правки научного руководителя

## 1. Потребление памяти: агент vs оператор (глава 2)

**Замечание:** Непонятно, почему оператор потребляет 40 МБ, а агент 64 МБ, хотя оператор обслуживает больше клиентов и должен хранить больше данных.

**Анализ:** Исходные цифры были взяты из документации двух разных продуктов HashiCorp: 64 МБ — Vault Agent, 40 МБ — Vault Secrets Operator. Разница обусловлена различиями в реализации этих продуктов, а не объёмом обслуживаемых данных. Сами токены и ключи занимают единицы килобайт, потребление памяти определяется рантаймом приложения.

**Решение:** Для упрощения и устранения путаницы используем одну и ту же цифру — 64 МБ на экземпляр — для обоих подходов. Ключевое различие в суммарном потреблении определяется количеством экземпляров (2300 агентов vs 90 операторов), а не потреблением каждого из них.

**Что изменилось:**
- Оператор: 40 МБ -> 64 МБ на экземпляр
- Память на контур: 0,7 ГБ -> 1,1 ГБ
- Суммарная память: 3,5 ГБ -> 5,5 ГБ
- В таблице сравнения обновлена строка «Память, ГБ»
- Добавлено пояснение: потребление определяется рантаймом, а не объёмом данных
